# ai_productivity
This ai will see on your computer if you are doing something productive or not productive. 
## setup
1. Make sure your jetson nano is already set up. 
2. Download the project using this command:`git clone https://github.com/zdflores/ai_productivity.git`
3. change directory with `cd ai_productivity`
4. Run this line in the terminal `python3 ./ai_productivity_monitor.py "input.png" "output.png"`
